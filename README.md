# NAS 多人在线聊天室

基于 NAS 共享文件夹实现的简易多人在线聊天程序。聊天记录以纯文本文件存储在 NAS 上，通过文件轮询实现实时刷新，无需服务器。

## 功能特性

- **多聊天室**：内置 5 个聊天室，用户启动时选择进入
- **实时聊天**：后台轮询 NAS 聊天文件，新消息自动刷新显示
- **文件共享**：
  - `/file <路径>` 上传文件到共享目录并自动分配编号
  - `/ls` 查看所有可下载的文件
  - `/dl <编号>` 下载文件到本地"下载"文件夹
  - `/rm <编号>` 删除文件（仅上传者可删）
- **跨平台**：支持 Windows / macOS / Linux
- **中文输入**：完整支持中文输入法
- **配置文件驱动**：所有路径、聊天室、用户名均可通过 `config.json` 配置

## 环境要求

- Python 3.6+
- 可访问的 NAS 共享目录（SMB 协议，Windows 网络共享）

## 快速开始

1. **配置 `config.json`**（首次使用必须修改）：

   ```json
   {
     "nas_path": "\\\\192.168.31.1\\共享",
     "sub_path": "chat-text",
     "files_sub_path": "files",
     "default_user": "你的用户名",
     "poll_interval": 1.0,
     "chat_rooms": [
       {"id": "chat-room1", "name": "闲聊大厅"},
       {"id": "chat-room2", "name": "技术讨论"},
       {"id": "chat-room3", "name": "游戏交流"},
       {"id": "chat-room4", "name": "生活分享"},
       {"id": "chat-room5", "name": "工作协作"}
     ]
   }
   ```

   > `nas_path` 为 NAS 共享根目录：
   > - Windows：`\\\\192.168.31.1\\共享`（UNC 路径）
   > - macOS / Linux：对应的挂载路径，如 `/mnt/共享`

2. **运行程序**：

   ```bash
   python chat.py
   ```

3. 输入用户名（或使用 `config.json` 中的 `default_user`），选择聊天室即可开始聊天。

## 使用说明

### 聊天

直接输入文字并按回车即可发送消息。空回车会重新显示输入提示。

### 文件命令

| 命令 | 说明 |
|------|------|
| `/file <路径>` | 上传本地文件到共享目录，自动分配编号 |
| `/ls` | 查看所有可下载的文件及编号 |
| `/dl <编号>` | 下载指定编号的文件到本地"下载"文件夹 |
| `/rm <编号>` | 删除指定编号的文件（仅上传者本人） |
| `/help` | 显示所有可用命令 |

### 文件目录结构

```
NAS 共享目录/
└── chat-text/
    ├── chat-room1.txt     # 各聊天室消息文件
    ├── chat-room2.txt
    ├── ...
    └── files/
        ├── files_index.json  # 文件编号索引（含上传者）
        └── (上传的文件)
```

## 配置文件说明

| 配置项 | 说明 |
|--------|------|
| `nas_path` | NAS 共享根目录路径 |
| `sub_path` | 聊天数据子目录（默认 `chat-text`） |
| `files_sub_path` | 文件共享子目录（默认 `files`） |
| `default_user` | 默认用户名，留空则启动时手动输入 |
| `poll_interval` | 新消息轮询间隔（秒） |
| `chat_rooms` | 聊天室列表（`id` + `name`） |

## 消息存储格式

聊天文件每一行格式为：`用户名: 消息内容`

```
张三: 大家好
李四: 你好呀
王五: [文件 #1] 上传了文件：报告.docx (128.5KB)
```

## 常见问题

**Q: 程序启动时用户名提示加载不出来？**
A: 用户名输入已提前到 NAS 访问之前执行，若仍卡顿请检查 `nas_path` 是否正确、NAS 是否在线。

**Q: 中文输入有问题？**
A: 程序使用 `input()` 整行输入，与中文输入法兼容。若使用 Windows Terminal 仍有异常，建议更新到最新版。

**Q: 其他用户看不到我上传的文件？**
A: 上传的文件和 `files_index.json` 都存放在共享目录，确保所有用户访问的是同一个 NAS 路径。
